# 待办清单

本 Skill 指导安装、预览与维护；常驻任务界面由 Obsidian 插件运行。内部 ID `note-trajectory` 为兼容已有数据保留，不代表存在笔记轨道。

## 选择入口

- **预览**：直接打开 [离线首页](assets/project/dist/index.html) 或 [每日统计](assets/project/dist/statistics.html)。内容为合成数据，与真实笔记库独立，不需要 Node 或网络。
- **安装/升级**：使用 [内置插件](assets/project/dist/plugin)，先读 [安装和开发](references/development.md)。目标笔记库必须由当前用户指定；只复制三个程序文件，保留个人 data.json。Skill 安装本身不等于同意安装 Obsidian 插件。
- **修改界面或逻辑**：用户已指定现有项目时使用该项目；否则将 [随包源码](assets/project) 复制到用户工作目录后修改，不直接修改安装的 Skill 资源。先读其 AGENTS.md、PRODUCT.md、DESIGN.md 及当前日志。
- **任务身份、持久化或统计问题**：先读 [数据规则](references/data-rules.md)，使用合成数据复现并独立核对原始事件/区间，不能仅验证页面数字自洽。

## 必须保留的行为

- 独立持久任务管理；超过五条未完成源任务且有新增时先征求该文件收录选择。完成、本地改名和删除不改写来源笔记。
- 手动 #标签匹配或创建模块；来源模块名称只读。模块删除仅删除关联手动任务，保留来源任务、笔记及历史。
- 上海时区的截止日期与上午/下午/时/分选择、天/小时提前量、截止升序及阈值名称变红；完成后恢复。任务不显示重复编辑说明，有 DDL 时仅悬浮时间。
- 首页单独显示模块，统计页区分当前累计与当日新增。记录时长只来自已保存活动区间，空闲/关闭期间不续算，不把笔记时间自动分摊到任务。
- 保留轻色圆角风格、实际容器宽度适配、键盘焦点、减少动态和保存失败恢复。笔记轨道与 Kanban 分发不属于当前运行功能。

每个完成阶段追加 `docs/交付日志.md` 并通知用户；每次用户修改追加 `docs/修改日志.md`。区分模拟、浏览器和真实宿主验证。只操作当前授权范围，合成实机数据在验证后清理。发布包不得含个人笔记、运行数据、备份、截图或密钥。运行无需会员、云服务或模型 API。
