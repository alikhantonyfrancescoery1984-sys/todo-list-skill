# 0.6.1 · 数据、接口与执行逻辑

当前插件没有远端统计接口。真实 Obsidian 使用官方 `loadData/saveData` 的本地持久数据；HTML 使用独立 localStorage 合成数据。两入口共享控制器、计算与组件。

| 显示/操作 | 唯一数据源 | 规则 |
| --- | --- | --- |
| 累计任务 | WorkspaceData.tasks | 排除 deletedAt，包含未完成及完成项；选历史日期时仍代表当前库存 |
| 当日新增 | State.receipts | 按上海日期、taskId 去重；首次导入/手动创建记一次，改字和重读不新增；删除不重写历史 |
| 当日完成 | State.completions | 当天完成过的 taskId 去重；可包含后来重开或删除的任务 |
| 近七天 | State.sessions | 所选日及前六日；开始排序、排除无效/超过一天区间、去重覆盖、上海零点裁剪后求毫秒；空白为 0 |
| 模块时长 | 同一 sessions + 当前 notes.path | DEFAULT_CONFIG.columnMap 最长目录前缀/目录别名，未匹配归 processing；移动后历史按当前路径归类 |
| 模块完成 | completions + tasks.moduleIds | 笔记项按路径；手动项按第一个标签，避免多标签重复；未打标签归手动待办 |
| 模块条形 | 模块记录秒数 ÷ 全日记录秒数 | 零时间不制造条长；隐藏模块不改总量，所以可见条形之和可能小于 100% |
| 标签 | 手动任务 text 中的 #词 | 支持汉字/字母/数字/下划线/短横线/斜线，以空白或逗号/分号分隔；NFKC、忽略大小写及空格/下划线/短横线后匹配名称/旧别名 |
| DDL/提醒 | tasks.dueAt / reminder | 上海日期＋可点击上午/下午＋时/分→带时区时间戳；提前量为非负天/小时，可小数；没有 DDL 不允许提醒 |

累计是清单库存，不是扫描整个库的文件数或所有 checkbox。只收录访问过且已索引、符合许可的笔记任务与手动项；超过 5 条未完成且有新项先询问。数据未记录以前的日期不补造。笔记记录时长不等于任务实际用时，任务用时保持“未记录”，不会自动分摊。

## 组件与接口

- `WorkspaceController.createTask(text, draftId, options)`：固定草稿 ID 防失败重试重复；解析手动标签、创建/复用模块、写首次事件并串行保存。
- `updateTask(id, text, {dueAt,reminder})`：手动正文更新标签；来源任务仅改本地 label。undefined 保留现有时间，null 清空。清空 DDL 同时清空提醒；来源同步不覆盖这些字段。
- `renameModule(id,name)`：仅活动手动模块可改名，保留旧别名及关联 ID；拒绝与现有来源/手动模块冲突。
- `removeModule(id)`：删除所有关联手动任务（包含已完成及多标签次成员）；软删除手动模块，来源模块只隐藏。笔记和来源任务保持；历史收录/完成/时长保留。
- `showModule(id)`：重新显示隐藏来源模块；再次明确添加该来源标签也恢复显示。不会恢复已删除任务。
- `taskInModule`/模块筛选：手动项匹配任一标签；统计完成只取主标签。因此多模块筛选可见同一任务，但汇总不会重复计数。
- `dailyStats(state,date,config,analyticsContext)`：使用完整 tasks/modules 上下文。快照的 state.taskRegistry 被置空，运行入口不能从它代替持久 tasks 计算累计数。
- `renderStatistics`：累计/新增/完成/笔记/时长、近七天、活动明细；七天按钮显式高度，柱条禁止收缩，保留 `data-seconds` 供独立核验。
- `renderModuleDistribution`：仅首页显示，每行输出来源 ID、类型、秒数、完成数并打开模块管理。
- `renderTasks`：未完成有 DDL 项先独立按绝对截止升序，无 DDL 在后继续原分组；不新增第二份任务。完成项保留历史。
- `taskEditor`/`moduleEditor`：两入口共用表单与校验、取消、错误重试。有 DDL 项悬浮仅展示绝对截止/提醒时间，不重复编辑名称；无 DDL 项不生成提示。可访问描述通过 hidden 与组件样式明确隐藏，不显示为第二行。
- `deadlineState`/`paintDeadlines`：当前时间 ≥ 提醒点即变红；无提前量则到期变红；逾期保持、完成取消。每秒局部更新，不重建编辑草稿；焦点/可见性恢复及重载重新判断。

关闭应用时不运行系统通知，重新打开按当前时间恢复红色。当前需求是界面提前警告，不包含系统推送。仅所记录活动计时，空闲/失焦/关闭期间不续算。

## 持久化与兼容

Workspace v5 / State v2 新增 manualModules、hiddenModules、task.moduleIds/dueAt/reminder。验证后升级旧 v2/v3/v4，旧图数据只聚合为每日笔记观察。保持任务身份、正文、状态、许可、来源及历史；全篇笔记正文不保存。未知版本、坏字段或坏引用拒绝覆盖。删除身份保留，防重新读取复活；序列化保存错误可见且可重试。

本地升级只替换三个程序文件，data.json 不被分发包覆盖。旧内部 plugin/view/command ID 为兼容保留，轨道功能仍完全移除。

M012 时间输入拆分为原生 date 与上午/下午、1–12 时、00–59 分下拉框。12 上午为 00 时，12 下午为 12 时；未修改本地分钟值时保留已有完整秒数/毫秒，清空日期同步清空提醒。
