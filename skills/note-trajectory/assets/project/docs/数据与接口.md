# 0.7.0 · 数据与接口

## 统计唯一来源

| 内容 | 来源与计算 |
| --- | --- |
| 累计任务 | tasks中过滤deletedAt，含未完成与完成项 |
| 当日新增 | receipts按上海日期筛选，对taskId去重 |
| 当日完成 | completions按上海日期筛选，对taskId去重 |
| 近七天 | 所选日及前6日，逐日计算当日完成数，无记录显示0 |
| 模块完成 | 当日唯一完成taskId映射来源当前目录或手动第一个主标签 |
| 模块条形 | 该模块完成数/当日全部完成数；隐藏模块不改总数，零完成无条长 |

完成历史不因重开或删除任务而移除。同日重复完成一次，不同日期可分别计一次。来源勾选完成按首次识别时刻记录，不推算历史日期。

## 已移除

不再采集、存储或计算时长。UsageRecorder、Session类型、空闲检查/区间收尾、时长裁剪合并、minutesLabel、时长摘要、活动明细及专用CSS已删除。旧sessions只在兼容迁移时丢弃；State v3无该字段。DDL时间输入与定时判断仍保留，独立于已删除的用时采集。

## 保持的接口

- WorkspaceController的createTask/updateTask/complete/removeTask与createGroup/renameGroup/removeGroup、标签模块/DDL/许可等行为保持。持久化继续串行保存，失败可重试。
- collect在索引确认后同步已有来源勾选；source unchecked不自动重开。deleteSourceTask唯一匹配删除源行，零匹配只删除旧账本项，多个候选拒绝；编辑器未保存时等待。
- renderStatistics保留累计/新增/完成/笔记摘要、日期导航，七天按钮输出data-completed；不再生成data-seconds、时长卡片或活动明细。
- renderModuleDistribution保留原模块管理动作与布局，模块行输出data-completed和按数量求得的百分比。
- 每日唯一笔记观察仍只保存noteId与date，不保存停留或开始结束时间。
